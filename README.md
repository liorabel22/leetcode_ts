# LeetCode TypeScript + Vitest

## Commands

- Install: `npm i`
- Test: `npm test`
- Watch tests: `npm run test:watch`
- Typecheck: `npm run typecheck`
- Lint: `npm run lint`
- Bench: `npm run bench`
